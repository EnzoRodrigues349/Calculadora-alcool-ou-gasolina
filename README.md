 Calculadora Álcool ou Gasolina:

Projeto web desenvolvido com HTML, CSS e JavaScript, criado para auxiliar na comparação entre os preços do álcool e da gasolina, indicando qual combustível oferece o melhor custo-benefício.

 Tecnologias utilizadas:
- HTML
- CSS
- JavaScript

Funcionalidades:
- Cálculo automático da melhor opção de combustível
- Comparação entre preço do álcool e gasolina
- Exibição dinâmica do resultado na tela
- Interface simples, intuitiva e responsiva

Projeto Online:
https://enzorodrigues349.github.io/Calculadora-alcool-ou-gasolina/

Objetivo do Projeto:
Este projeto foi desenvolvido para praticar lógica de programação, manipulação de dados com JavaScript e interação com o usuário através de formulários e cálculos dinâmicos.
